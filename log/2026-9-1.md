```text

过滤大于 10GHz 的明显异常 TSC 频率。
当虚拟化频率来源和 PIT fallback 都不可信时，兜底使用当前环境真实量级 2.5GHz。
```

## 2. 实现 Device Mapper zero target

### 背景

继 `error` target 后，继续补一个边界清晰的基础 DM target。`zero` target 不依赖 backing device：读返回全 0，写入丢弃并成功完成，可用于补齐 `dmsetup targets`、`target-version` 和 raw 数据面基础覆盖。

### 改动

新增 zero target 核心实现：

```text
kernel/core/comps/device-mapper/src/target/zero.rs
kernel/core/comps/device-mapper/src/target/mod.rs
kernel/core/comps/device-mapper/src/table.rs
kernel/core/comps/device-mapper/src/lib.rs
```

主要行为：

```text
zero target 不接受 backing 参数。
Read BIO 填充全 0 后以 Complete 完成。
Write BIO 丢弃并以 Complete 完成。
Flush 对无 backing table 直接 Complete。
deps 为空，metadata 容量来自 target 长度。
```

接入 ioctl / dmsetup 控制面：

```text
kernel/core/src/device/misc/device_mapper.rs
myshell/run_dmsetup_cli_semantics_test.sh
myshell/run_dmsetup_linux_cli_baseline.sh
```

主要行为：

```text
dmsetup targets 列出 zero v1.1.0。
dmsetup target-version zero 返回 1.1.0。
dmsetup create/table/status/deps/remove 支持 zero。
系统脚本验证 zero 读全 0、写成功且写后仍读全 0。
```

扩展 raw 数据面边界脚本和测试说明：


## 6. 接入 discard / write zeroes 通用 range BIO 与 DM 映射

### 背景

在确认本阶段可以接受“基于已有 Asterinas block/BIO/driver/ioctl 抽象新增能力，但不引入 udev 类新框架或大规模重构”后，重新推进 discard / write zeroes。目标是让该能力成为通用 block range BIO，并让 DM 复用现有 split/remap/direct-complete 路径。

### 改动

```text

kernel/core/comps/block/src/impl_block_device.rs
kernel/core/comps/device-mapper/src/device.rs

docs/test.md
log/device-mapper-progress.md
```

主要行为：

```text
block 层新增 BioType::Discard / BioType::WriteZeroes、Bio::new_range 和 range-only split。
BlockDevice 增加 discard_sectors / write_zeroes_sectors 及异步便捷 API。
readonly mapper 将 Write / Discard / WriteZeroes 都视为 write-like 并拒绝。
DM table 对 linear/striped 复用现有 split/remap；error target 返回 I/O error；zero target direct-complete。
block ioctl 接入 BLKDISCARD / BLKZEROOUT，并补 legacy BLKSSZGET 以适配 util-linux blkdiscard。
virtio block 协商 DISCARD / WRITE_ZEROES feature 后下发 VIRTIO_BLK_T_DISCARD / VIRTIO_BLK_T_WRITE_ZEROES。
NVMe 暂未接真实 Dataset Management / Write Zeroes 命令，对 range BIO 明确返回 NotSupported。
系统脚本增加 zero target 上 blkdiscard / blkdiscard -z 验收。
技术文档、测试说明和滚动进度文档同步为当前边界。
```
