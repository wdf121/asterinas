## 1. 补充 mixed table active / inactive 替换 ktest

### 背景

前面已覆盖 mixed table 的 inactive 控制面和 active 数据面。本阶段继续补状态机边界：运行中的 DM 设备已有 active linear table 时，通过 ioctl load 一个 mixed linear + striped inactive table，在 resume 前 active 查询仍应返回旧表，inactive 查询返回 mixed 新表；resume 后 active 应切换到 mixed table，inactive 清空，deps 也应切到 mixed backing 集合。

### 改动

`kernel/src/device/misc/device_mapper.rs`：

```text
新增 resume_replaces_active_linear_table_with_ioctl_loaded_mixed_table，覆盖 running device 中 active linear table 被 ioctl loaded mixed table 替换的状态机路径。
验证 resume 前 active / inactive table status 分离，resume 后 active table status 和 deps 均切换到 mixed table，inactive table 清空。
```

本阶段不新增 QEMU/NixOS 系统测试入口，不涉及 udev / devtmpfs / systemd 联动。
