## 1. 补充 mixed table active / inactive 替换 ktest

### 背景

前面已覆盖 mixed table 的 inactive 控制面和 active 数据面。本阶段继续补状态机边界：运行中的 DM 设备已有 active linear table 时，通过 ioctl load 一个 mixed linear + striped inactive table，在 resume 前 active 查询仍应返回旧表，inactive 查询返回 mixed 新表；resume 后 active 应切换到 mixed table，inactive 清空，deps 也应切到 mixed backing 集合。

### 改动

`kernel/src/device/misc/device_mapper.rs`：

```text
新增 resume_replaces_active_linear_table_with_ioctl_loaded_mixed_table，覆盖 running device 中 active linear table 被 ioctl loaded mixed table 替换的状态机路径。
验证 resume 前 active / inactive table status 分离，resume 后 active table status 和 deps 均切换到 mixed table，inactive table 清空。
```

本阶段不新增 QEMU/NixOS 系统测试入口，不涉及 udev / devtmpfs / systemd 联动。

## 3. 新增 mixed linear + striped LVM2 系统验收

### 背景

前面已通过 ktest 覆盖 linear + striped mixed table 的 ioctl 控制面、数据面和 active/inactive 替换。本阶段补真实 LVM2/libdevmapper 路径：先在 PV1 上创建 linear LV，再用 PV2+PV3 做 2-way striped 扩容，使同一个 LV 自然生成 linear + striped mixed table，并验证重启后可恢复和读取数据。

### 改动

新增脚本：

```text
myshell/dm_mixed/run_lvm2_linear_striped_mixed_reboot_test.sh
```

新增组合入口：

```text
myshell/run_dm_system_tests.sh --mixed-lvm2
```

默认覆盖：

```text
三块 512 MiB 测试盘
PV1 创建 256M linear LV
PV2+PV3 扩容到 512M，形成第二段 2-way striped segment
64 MiB base 文件
256 MiB grow 文件
重启后 readonly mount + md5 复查
```

`--full` 语义保持不变，不加入 mixed / striped 慢速矩阵。本阶段不涉及 udev / devtmpfs / systemd 自动联动。

## 4. 合入当前 main 并适配 kernel/core 目录迁移

### 背景

当前 `main` 已将内核 crate 拆分为 `kernel/core` 结构，旧的 `dm` patch 无法直接应用到更新后的 `main`，首个失败点是 `Cargo.lock` 的旧基线上下文。本阶段将当前 `main` 合入 `dm`，并把 DM 相关改动迁移到上游的新目录布局。

### 改动

路径迁移：

```text
kernel/comps/device-mapper -> kernel/core/comps/device-mapper
kernel/src/device/misc/device_mapper.rs -> kernel/core/src/device/misc/device_mapper.rs
kernel/src/fs/fs_impls/procfs/devices.rs -> kernel/core/src/fs/fs_impls/procfs/devices.rs
```

依赖和集成调整：

```text
根 Cargo workspace 改为引用 kernel/core/comps/device-mapper。
kernel 外壳保持上游 aster-core 结构，DM 依赖接入 kernel/core/Cargo.toml。
block registry 保留 DM 引入的 lease / pending registration / pending unregistration 语义，同时合入上游 lookup_by_name 和 scan_partitions。
FsCreationCtx 继续为普通 mount 持有 BlockDeviceLease；rootfs 预解析设备通过不参与注册表生命周期的 lease 包装接入。
```

本阶段不新增 NixOS/LVM2 系统验收入口，不改变 `--full` 语义。
