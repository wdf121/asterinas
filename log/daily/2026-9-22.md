# 2026-9-22

## Device Mapper 系统测试与日志收敛

### 变更

- 将 DM NixOS harness 收敛为每个 suite 一个权威 `/tmp/*-test.log`：host `HOST_*` 事件与 QEMU/guest 输出通过运行期 FIFO 进入单一 writer，避免并发追加导致 host 标记与 guest prompt 拼接；suite 退出后 FIFO 自动删除。
- 移除 QEMU 并发检查在成功路径遗留空 `*-qemu-running.txt` 的行为；已有 QEMU 时，将失败标记及 PID/命令行直接写入对应 suite 日志。
- 统一将六个 suite 的 host 信息、超时、失败和通过标记写入其 suite 日志；统一 selector 的 `HOST_PASS_DM_SYSTEM_TESTS` 也追加到同一日志。
- 修正 LVM2 topology 的跨 PV linear LV 报表断言：`lvs` 请求 `segtype` 时会按 segment 返回重复汇总行，改为以 LV 汇总行验证 `seg_count=2`，并保留 DM table/dependencies 对两个 backing 的验证。
- 更新 `docs/test.md`、`log/device-mapper-progress.md`、`log/device-mapper-optimization-v4.md` 与 `docs/review.md`，记录单一 suite 日志模型、系统验收结果和 LVM2 报表断言边界。
