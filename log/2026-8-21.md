## 1. 新增 LVM2 striped multi-segment 系统验收

### 背景

`striped` 已覆盖 raw BIO、2-way LVM2 create/grow/shrink/reboot，以及 3PV / 3-way reboot。当前还缺真实 LVM2 生成多个 striped segment 的系统验收。

本阶段只验证 multi-segment create/extend/reboot recovery，不混入 shrink；shrink 仍由 2-way LVM2 主脚本覆盖。

### 改动

新增脚本：

```text
myshell/dm_striped/run_lvm2_striped_multi_segment_reboot_test.sh
```

默认覆盖：

```text
三块 512 MiB 测试盘
PV1+PV2 创建 256M 2-way striped LV
PV2+PV3 扩容到 512M，形成第二段 striped segment
64 MiB base 文件
256 MiB grow 文件
重启后 readonly mount + md5 复查
```

first guest 流程：

```text
检查 /dev/mapper/control 和 striped target
定位 vdmtest / vdmtest2 / vdmtest3 三块测试盘
pvcreate PV1/PV2 + vgcreate
lvcreate --type striped -i 2 -I 4K -L 256M，限定 PV1+PV2
检查 initial dmsetup table/status/deps
mkfs.ext2 + 写 base 文件 + md5sum -c
pvcreate PV3 + vgextend
lvextend -i 2 -I 4K -L 512M，限定 PV2+PV3
检查 extended dmsetup table/status/deps 至少两段 striped、3 dependencies
离线 e2fsck + resize2fs + e2fsck
写 grow 文件 + md5sum -c
vgchange -an + poweroff
```

second guest 流程：

```text
重新定位三块测试盘
pvscan / vgscan --mknodes / vgchange -ay
检查 recovered dmsetup table/status/deps 仍为 multi-segment striped
readonly mount
md5sum -c striped-ms.md5
读取 base marker 和 grow marker
vgchange -an + poweroff
```

新增组合入口：

```text
myshell/run_dm_system_tests.sh --striped-lvm2-multi-segment
```

`--striped`、`--striped-lvm2`、`--striped-lvm2-3pv` 和 `--full` 语义保持不变，`--full` 不加入 striped 全量。

测试说明和技术维护文档同步记录 multi-segment 入口、默认参数、通过标记和验证矩阵。

## 2. 补充 Device Mapper linear / striped 非法参数 ktest

### 背景

系统验收已经覆盖 `linear` 和 `striped` 的主要正常路径；本阶段补内核级错误输入测试，确认非法 table 参数会被拒绝，并且失败的 table load 不会改变 DM 设备状态。

### 改动

`kernel/src/device/misc/device_mapper.rs`：

```text
扩展 linear ioctl table-load 非法参数测试，覆盖缺少 backing、缺少 start、额外字段、bad major/minor、bad start 和 start 溢出。
扩展 striped ioctl table-load 非法参数测试，补充 stripe_count 非数字和 chunk_size 非数字。
```

`kernel/comps/device-mapper/src/target/striped.rs`：

```text
补充 StripedTargetParams::parse 对 stripe_count 非数字和 chunk_size 非数字的直接 parser 测试。
```

本阶段不新增 QEMU/NixOS 系统测试入口，不改变 `myshell` 启动协议。

## 3. 补充 Device Mapper table-load 边界 ktest
